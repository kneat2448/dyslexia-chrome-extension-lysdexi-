# lysdexi Privacy Notes

lysdexi is designed as an offline dyslexia reading layer.

## Data stored locally

- Extension settings
- Reading profile choice
- Toolbar position
- Ruler height and color
- Local compatibility reports

## Compatibility reports

When the user clicks **Report this site**, lysdexi stores a local report containing:

- Site domain and page path
- Extension version
- Browser user agent
- Selected lysdexi settings relevant to compatibility
- Timestamp

Reports do not include page text, selected text, passwords, form values, screenshots, or full browsing history.

## Network

The current version does not send reading content or settings to a server.
